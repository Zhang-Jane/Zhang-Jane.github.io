## Google 排名的因素（随着时间会改变，需要关注官方最新的算法）

2025 排名因素：<sup>[<a href="#fn-notes4">〔注4〕</a>]</sup>

很多时候不是不会做，而是做错了重点。  
SEO 不是改几个标签就能起飞，它更像一个组合拳：内容匹配 + 站点结构 + 技术可抓取 + 链接信号 + 用户反馈。

如果要压成一句话：

- 相关性决定你有没有资格被匹配到；
- 权威性决定你能不能往前排；
- 用户行为决定你能不能稳住。

注意的是：Google 在 2026 年进一步强化了用户体验信号、实体理解、AIO 友好度、真实经验（Experience）

### 2026 年 Top 8 实用排名因素（优先级排序）

1. **高质量、有帮助的内容 + 真实 Experience（E-E-A-T）** 必须提供“Authentic Utility”（真实价值 + 第一手经验）。AI 生成的薄内容被重罚。

2. **用户满意度信号（NavBoost / Clicks）** 停留时间、Selection Rate、低跳出率是最强信号之一。短期刷 CTR 已基本无效。

3. **实体建设（Entity SEO）** Knowledge Graph 认可、Schema + sameAs、About 页清晰、品牌搜索可见度。Disconnected Entity 是 HCU 等降权主因。

4. **搜索意图匹配 + 查询类型适配** Google 内部 8 类查询（Short Fact、Comparison、Instruction 等），内容结构必须匹配（用 MWC RQ Predictor 工具检查）。

5. **技术体验（Page Experience）** Core Web Vitals（LCP、INP、CLS）、移动友好、页面速度、llms.txt（帮助 AI 读取）。

6. **品牌信号与权威（Brand Authority）** 品牌搜索量、第三方提及、Trustpilot 等真实评价。Domain Authority 远高于 Brand Authority 的“合成权威”站易被打。

7. **优质 Backlinks + Topical Authority** 数量不如质量和相关性重要。自然、上下文相关的链接仍强。

8. **新鲜度（Freshness）** 只对 QDF 查询（新闻、事件、频繁变化话题）重要。大多数查询中，老内容 + 持续维护更占优

## 关键词

### 常见四种搜索意图

- 交易型：要买、要下单、要注册。
- 信息型：想知道是什么、为什么、怎么做。
- 商业调研型：对比、评测、推荐、避坑。
- 导航型：要找某个品牌或某个具体页面。

### 如何选择关键词（落地）

- 一个页面尽量只打一个主意图。
- 标题、首段、H2 和 CTA 都围绕同一件事。
- 不要死堆关键词，做语义相关覆盖就够了。

### 长尾词别当“冷门词”理解

长尾词本质是“更具体、意图更清晰”的词。  
它不一定流量大，但通常竞争小、转化高，新站更容易做出结果。

## 已经上线的网站 seo 优化

### Title、Description、Keyword、Structured 等信息展示是否清晰

- 对相关性和点击都很关键。
- 关键词可以前置，但先保证人能看懂。
- 写得太像关键词列表，Google 可能直接给你重写。

### 正文内容

- Google 主要靠正文判断页面主题。
- 位置通常比频次更重要：标题区、首段、关键小节。
- 内容最好能回答三个问题：用户遇到什么问题、你怎么解决、结果是什么。

### Meta Description

- 主要影响点击率，不是直接排名因子。
- Google 会按查询词改写摘要，这是常态<sup>[<a href="#fn-notes1">〔注1〕</a>]</sup>。
- 写 description 的目标是“让人愿意点”，不是塞更多词。

### URL 与关键词

- URL 里的关键词是弱信号，别太迷信。
- 保持简洁、稳定、可读，比“塞词”更重要。

### Meta Keywords

这个字段对 Google 网页排名基本没用<sup>[<a href="#fn-notes2">〔注2〕</a>]</sup>，可以不花时间。

---

### canonical

当站内有相似页面（参数页、排序页、同内容多路径）时，`rel="canonical"` 可以告诉搜索引擎你希望以哪个版本为主。

- canonical 不是“禁止收录”按钮。
- 站内信号不要互相打架（canonical 指向 A，内链却一直推 B）。
- 规范页要能访问、内容完整、可索引。

### 内链是否合理

#### 为什么要做内链

- 用户能更快找到下一步内容；
- 爬虫更容易发现深层页面；
- 站内权重能更合理地流动。

#### 内链结构建议

- 首页 -> 栏目页 -> 内容页，层级尽量清楚。
- 重点页面不要埋太深，常见建议是 3-4 次点击内可达。
- 新页面上线后，尽快从高权重页面给到上下文内链。

#### 内部链接的类型

- 导航链接：主干路径，最基础也最重要。
- 面包屑：让用户知道“我在哪一层”。
- 上下文链接：正文里自然带出相关页面。
- 页脚链接：补充用，别承担主导航职责。

## 内链评估

### 主要评估维度与方法

- 有没有孤立页（没人链接到它）。
- 关键页面有没有足够入链。
- 锚文本是否自然，是否全站重复一个词。
- 页面深度是否过深，是否有死链。
- 用户行为有没有变好（停留、访问深度、跳出）。

## 外链

### 如何查看外链

- External Link：从你网站链出去的链接（外链/出站）。
- Backlink：别人链向你网站的链接（反链）。
- Internal Link：你站内页面之间的链接（内链）。

同一条链接，从不同站点视角看，名字确实不一样。

### 方法一：查看自己网站的外链（最推荐）

工具：Google Search Console（GSC）<sup>[<a href="#fn-notes8">〔注8〕</a>]</sup>。

常用路径：

1. 登录 GSC；
2. 左侧菜单进入“链接（Links）”；
3. 查看“外部链接（External links）”模块；
4. 重点看这三块：
   - Top linked pages（被链接最多的页面）
   - Top linking sites（主要引荐站点）
   - Top linking text（主要锚文本）

优点是数据权威、免费、稳定；  
限制是只能看你有权限的网站。

### 方法二：查看竞品网站外链（第三方工具）

如果要看竞争对手，通常要用第三方工具：

- Ahrefs：外链库大，适合做结构分析<sup>[<a href="#fn-notes7">〔注7〕</a>]</sup>；
- SEMrush：功能全面，适合综合分析<sup>[<a href="#fn-notes16">〔注16〕</a>]</sup>；
- Moz：老牌工具，适合补充 DA 视角<sup>[<a href="#fn-notes29">〔注29〕</a>]</sup>；
- Ubersuggest：上手简单，适合快速初筛<sup>[<a href="#fn-notes18">〔注18〕</a>]</sup>。

注意：不同工具口径不同，数字不一致是正常现象。  
做决策时看趋势和结构，不要只盯某一个绝对值。

### 方法三：`link:域名`（补充参考）

`link:` 这种老搜索指令可以偶尔当补充参考，  
但不建议作为主要外链分析方法。

### 反向链接中一些重要指标（增长看板）

- 引荐域名净增长（新增 - 流失）。
- 外链总量趋势（辅助看，不当核心 KPI）。
- 属性分布：dofollow / nofollow / sponsored / ugc。
- 锚文本结构：品牌词、URL、泛词、关键词词组。
- 链接落点：首页、内容页、商业页各占多少。
- 丢链原因：页面删了、404、改 nofollow、站点失效等。

### 质量类（Quality / 质）

- 来源主题和目标页面是否相关。
- 链接在正文里还是模板位（正文编辑链接通常更有价值）。
- 来源页本身有没有流量、是否被正常索引。
- 是长期稳定链接，还是短期冲量后消失。

### 风险类（Risk / 防踩坑）

- 短期突然涌入一堆低质域名。
- 来源大量集中在同类站群或同 IP 段，且和业务不相关。
- 精准匹配锚文本比例异常高。

## 技术项

### Heading Tags 合理使用

- 层级别乱跳。
- H 标签是为了组织内容，不是关键词装饰位。

### ALT（图片替代文本）

- 写清图片内容，兼顾无障碍和图片检索。
- 不要把 ALT 变成关键词堆砌区。

### 看是否有 sitemap

- 站点要有可访问 sitemap。
- 站点越大，sitemap 对新页发现越关键。

### Robots 禁止一些没有用的网页

- 可以拦截低价值或浪费抓取预算的页面。
- 但一定小心别把核心页面误伤了。

### Nofollow

`nofollow`、`sponsored`、`ugc` 这几个属性在你原笔记里是重点，实际使用时按链接场景区分。  
广告、赞助、UGC 链接优先用对应属性<sup>[<a href="#fn-notes3">〔注3〕</a>]</sup>。

### Social Media Meta Tags（社交媒体元标签）

这类标签不直接决定 Google 排名，但会影响社交平台的展示和点击。  
常用字段是 `og:title`、`og:type`、`og:image`、`og:url`。

1. **`og:title` (标题)**：
   - 告诉社交平台，这张卡片的标题是什么。
   - _注意：_ 它通常可以和你的 SEO Title 不一样！你可以专门为社交媒体写得更“标题党”一点。
2. **`og:type` (类型)**：
   - 告诉平台这是什么东西。
   - 一般是 `website` (网站首页) 或 `article` (文章页)。
3. **`og:image` (图片)**：
   - **这是最重要的！**
   - 一张好看的大图能让点击率翻好几倍。如果没有指定，平台会随机抓取，效果通常很惨。
4. **`og:url` (网址)**：
   - 这张卡片对应的永久链接

### JSON-LD（JavaScript Object Notation for Linked Data）

结构化数据是给机器看的“说明书”，能帮助理解页面类型和实体。  
但它不是内容质量不足时的补药。

### hreflang meta 标签的意义

做多语言/多地区站点时要认真配，不然容易出现版本错投和重复竞争。

它的核心意义：让对的人看对的页面
试想一下，如果你的网站有三个版本：

1. **英文版（针对美国）：** 价格是美元 ($)，用词是 "Color"。
2. **英文版（针对英国）：** 价格是英镑 (£)，用词是 "Colour"。
3. **中文版（针对中国）：** 全中文内容。
   如果没有 `hreflang` 标签：

- 一个英国用户在 Google 搜索你的产品，Google 可能会错误地把**美国版**（美元价格）展示给他。用户一点进去发现是美元，觉得麻烦，马上关掉（跳出率升高）。
- 或者 Google 觉得你的美国版和英国版内容 99% 是一样的，判定你为“重复内容” (Duplicate Content)，把你两个页面都降权。

**`hreflang` 的作用就是告诉 Google：**

> “嘿 Google！这三个页面其实是‘一家人’。
>
> - 如果是**美国**用户，请让他看**页面 A**；
> - 如果是**英国**用户，请让他看**页面 B**；
> - 如果是**中文**用户，请让他看**页面 C**。

### Google Search Console 的曝光很高，但是点击率极低，是为什么？

这类问题几乎每个站都会遇到，按这个顺序查最省时间：

1. 平均排名是不是本来就在 5-10 名以后；
2. 数据里是不是混了图片搜索（曝光高、点击低很常见）；
3. 标题有没有被截断，或者和别人比没有区分度；
4. description 是否太空泛，没说清价值；
5. 页面类型和查询意图是不是错位；
6. 是否在 PAA/相关搜索这类“看得到但不容易点”的位置；
7. 是否属于零点击查询（用户在搜索页直接拿到答案）。

所以“CTR 低”不必先怪内容，先把位置、意图、展示位拆开看。

## Google 的搜索结果（SERP）描述与网页设定的 meta description 不一致

因为它会按当前 query 去选“更匹配”的片段。  
同一页面面对不同搜索词，出现不同摘要是正常行为。

### 为什么会不一致

- snippet 主要是为了匹配当前查询，不是为了照抄你写的描述；
- 同一页面在不同 query 下，Google 可能选不同正文片段<sup>[<a href="#fn-notes9">〔注9〕</a>]</sup>；
- 如果 meta description 太泛、太空、与正文不一致，被改写概率会更高。

### Query-Dependent 这点怎么理解

简单说就是“看人下菜”：

- 用户搜“产品名”，系统更可能选品牌和功能概述；
- 用户搜“产品名 + 价格”，系统更可能选正文里带价格的信息片段。

同一个页面，不同查询显示不同摘要，是机制设计，不是异常。

### 怎么提高被采用概率

- description 写“页面给用户什么价值”，不是关键词列表；
- 正文开头放一段可直接当摘要的完整句；
- 不要全站复用同一段 description；
- 接受“可被改写”这个事实，重点是让改写后也不跑偏。

### 两个典型场景（按原笔记思路）

场景 A：用户搜“产品名”  
如果你写的 description 正好覆盖品牌和核心卖点，往往更容易被用。

场景 B：用户搜“产品名 + 价格/折扣”  
如果正文里有更匹配的价格信息，Google 往往会抽正文而不是 description。

## E-E-A-T

### Experience（经验）

有没有第一手证据：实拍、实测、复盘、踩坑记录。

### Expertise（专业性）

有没有专业判断：方法、边界、术语、验证过程。

### Authoritativeness（权威性）

有没有被行业认可：被引用、被提及、被高质量站点链接。

### Trustworthiness（可信度）

网站是不是让人放心：身份透明、引用可追溯、站点安全、页面体验干净。

建议保留的动作：

- 做作者页和“关于我们”；
- 关键观点给来源；
- 评测内容尽量有实拍实测。

## Google 排名因素概览

参考：

- First Page Sage 排名因素参考<sup>[<a href="#fn-notes5">〔注5〕</a>]</sup>
- Backlinko 排名因素参考<sup>[<a href="#fn-notes4">〔注4〕</a>]</sup>

| 排名因素                                                               | 权重 | 趋势     |
| ---------------------------------------------------------------------- | ---- | -------- |
| 持续发布令人满意的内容（Consistent Publication of Satisfying Content） | 23%  | 上升     |
| Meta 标题中包含关键词（Keyword in Meta Title Tag）                     | 14%  | 微降     |
| 反向链接（Backlinks）                                                  | 13%  | 持平     |
| 利基领域专业度（Niche Expertise）                                      | 13%  | 持平     |
| 搜索者参与度（Searcher Engagement）                                    | 12%  | 上升     |
| 内容新鲜度（Freshness）                                                | 6%   | 明显上升 |
| 移动端友好 / 移动优先（Mobile-Friendly / Mobile-First）                | 5%   | -        |
| 可信度（Trustworthiness）                                              | 4%   | -        |
| 链接分布多样性（Link Distribution Diversity）                          | 3%   | 新增关注 |
| 页面速度（Page Speed）                                                 | 3%   | -        |
| 网站安全（Site Security / SSL）                                        | 2%   | -        |
| 内部链接（Internal Links）                                             | 1%   | 下降     |
| 其他因素（Meta Description、Schema 等）                                | 1%   | -        |

#### 1. 持续发布令人满意的内容（23%）

这一条在原笔记里是核心中的核心。  
重点不是“发了没”，而是“有没有真正满足搜索意图”。  
如果只是平均水平内容，现在很难拿到稳定排名。

#### 2. Meta 标题中包含关键词（14%）

标题里包含关键词依然重要，但写法上要自然。  
关键词堆砌会影响可读性，也容易被改写。  
原笔记强调的是“相关 + 可读”，不是“生硬匹配”。

#### 3. 反向链接（13%）与利基专业度（13%）

这两个维度可以放在一起看：

- 反向链接解决的是“外部信任投票”；
- 利基专业度解决的是“你是不是这个领域的稳定内容提供者”。

原笔记里提到的 Hub & Spoke 也属于这个逻辑：  
用核心页 + 长尾支撑页形成专题深度，持续累积主题权重。

#### 4. 搜索者参与度（12%）

这部分看的是用户真实反馈。  
比如点进来后很快离开，或停留很短，通常都不是好信号。  
所以内容结构、可读性、页面体验会直接影响排名稳定性。

#### 5. 内容新鲜度（6%）

原笔记给到的重点是：  
持续更新通常比“发完不管”表现更好，尤其是时效性强的主题。  
这也是为什么老文章要定期回炉，而不是只做新发文。

#### 6. 移动优先（5%）

移动端体验已经是基础能力，不是加分项。  
如果移动端慢、布局乱、交互差，会拖累整体表现。

### 值得注意的变化与趋势

- 内链仍然重要，但“只靠内链操作”很难成为主要增长来源。
- 技术项（Schema、URL 关键词、H 标签关键词）更像基础盘，不是决定性杠杆。
- 链接分布多样性值得重视：外链如果只集中首页，效果通常不如分布到关键内容页。

### 怎么用这组因素

- 用它排优先级，不要把它当精确计算公式。
- 把“内容质量 + 用户反馈 + 主题深度”作为长期主线。
- 把 GSC 数据和转化数据作为最终复盘依据。

## 在谷歌上获得排名需要多长时间？

Ahrefs 页面排名周期研究<sup>[<a href="#fn-notes6">〔注6〕</a>]</sup>

关键结论（2025 年更新版）：

- 只有 1.74% 的新页面在发布后一年内进入 Google Top 10（2017 年是 5.7%）。
- Top 10 页面中，72.9% 超过 3 年老（2017 年是 59%）。
- 第一位置的平均页面年龄：5 年（2017 年是 2 年）。
- 高搜索量关键词排名更难，但一旦排名可能更快（早期冲刺）。

### 1. 排名靠前的页面大多是“老页面”

按你原笔记里的结论，Google 前排结果里，页面年龄普遍偏大。  
也就是说，时间本身就是一种信任累积，尤其在竞争词上更明显。

常见现象：

- 前 10 结果里，老页面占比通常更高；
- 排名越靠前，页面“资历”往往越老。

### 2. 新页面一年内进首页，难度很高

新页面当然有机会，但比例并不高。  
这也是很多人会误判的地方：内容上线几个月没动静，未必是策略错了，也可能只是还在积累期。

实操上要接受两件事：

- 新页不是发出去就有排名；
- 早期表现波动很大，先看趋势不要急着下结论。

### 3. 能起来的页面，也常见 2-6 个月爬坡

即便是能在一年内进前列的页面，也很少“一夜冲上去”。  
多数还是经历一段爬坡期，常见区间就是 2-6 个月。

这段时间更该做的是：

- 持续补全内容；
- 调整标题和摘要点击率；
- 补内链和相关外链；
- 根据 GSC 查询词做二次对齐。

### 4. 更快起量的常见组合：高权重 + 低竞争

原笔记里提到的捷径可以概括为两点：

- 站点基础权重高（老站、强站）；
- 目标词竞争不高（长尾或细分词）。

这两个条件只要满足一个，通常就比“新站 + 大词”更容易起量；  
两个都满足时，起量速度通常会更快。

### 5. 大词 vs 小词：不是只看流量大小

直觉上大家都觉得大词更难，这没错。  
但是速度问题还和“谁在竞争”有关：

- 大词竞争者多是高权重站点，一旦它们发了强内容，可能很快被推上去；
- 小词虽然竞争小，但也可能走慢爬坡路线。

所以判断“多久能起来”，不能只看词量，还要看站点基础、竞品强度和内容质量。

### 小结

- 新站优先做低竞争长尾词，先拿确定性流量；
- 老文章按季度更新，别只追新发；
- 复盘周期按月看动作、按季度看结果，比按周盯排名更稳。

## 三句话总结谷歌排名到底怎么回事

### Title 和 H1：决定你能不能进入候选池（相关性）

页面主题先要被识别对。  
如果标题和页面内容都没有对上关键词意图，后面的优化空间很小。

### 外链：决定你能不能进前排（权威性）

当很多页面都讲同一主题时，外链本质是在做“外部投票”。  
高质量、相关站点的链接，通常更能支撑前排竞争。

### 用户体验与行为：决定你能不能稳住位置（用户信号）

进前排只是第一步。  
点击后停留、跳出、继续浏览等行为，会持续影响位置稳定性。  
所以最后拼的还是内容质量和页面体验。

## 每月执行清单

1. 复盘高曝光低 CTR 查询，先分类型再改页面。
2. 更新 3-5 篇旧内容（标题、首段、意图匹配、内链补齐）。
3. 继续铺主题集群（核心页 + 长尾支撑页）。
4. 修复死链、失效内链，减少孤立页。
5. 追踪引荐域名净增长和关键页丢链。
6. 检查 sitemap、覆盖与抓取异常。
7. 抽查结构化数据和社交分享卡片。
8. 每月补充可验证证据（数据、实测、案例），持续强化可信度。
